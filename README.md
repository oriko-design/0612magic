# ✨ マジックフィンガー

パソコンのカメラに映った手を認識して、指先の動きに合わせてキラキラした魔法の軌跡を描けるゲームです。

## 遊び方

- ☝️ **指を動かす** … 人差し指の先から青白いキラキラの魔法が出て、動かした軌跡がしばらく残ります
- 🖐️ **手をパーに開く** … 手のひらから「パーッ!!」と魔法が放射状に弾ける特殊演出が発動します(開いている間はオーラが漂います)
- 両手(2つまで)同時に使えます
- 左上の「軌跡を消す」ボタンで画面をリセットできます

## 起動方法

カメラを使うため、`https` または `localhost` で開く必要があります。ファイルを直接開くのではなく、簡易サーバーを立ててください。

```bash
# Python がある場合
python3 -m http.server 8000

# Node.js がある場合
npx serve .
```

ブラウザで `http://localhost:8000` を開き、カメラの使用を許可してください。

## 技術構成

- **手の検出**: [MediaPipe Hands](https://developers.google.com/mediapipe)(CDN 読み込み・ブラウザ内で動作)
- **エフェクト描画**: Canvas 2D + 加算合成によるパーティクルシステム
  - ボケた光球・鋭いスパークル・十字の星型フレアの3種類を組み合わせて、幻想的な青い光を表現
- サーバー処理は不要で、すべてブラウザ内で完結します(初回のみ CDN からモデルを取得するためネット接続が必要です)

## 動作環境

- Chrome / Edge / Safari などの最新ブラウザ
- Web カメラ
